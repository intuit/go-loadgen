# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in go-loadgen, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, please [report it privately](https://github.com/intuit/go-loadgen/security/advisories/new) with:

- A description of the vulnerability
- Steps to reproduce the issue
- The version of go-loadgen (`loadgen --version`) and of Go you are using
- Your assessment of the severity

## Supported Versions

Only the latest release of go-loadgen receives security fixes. go-loadgen is built and tested with the Go releases that are currently supported by the Go team.
